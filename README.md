## Contents

- `index.html` — all page content and metadata
- `styles.css` — complete responsive design system and layouts
- `app.js` — mobile menu, active navigation, and email-copy interaction
- `assets/` — hero artwork, app artwork, local Inter fonts, résumé, and favicon

## Run locally

Open `index.html` directly in a browser, or serve this directory with any static file server.

## Deploy

This folder is ready for any static host. No build command or package installation is required.

- GitHub Pages: upload the folder contents to a repository and enable Pages from the repository root.
- Netlify: drag this folder into Netlify Drop.
- Vercel: import the repository, choose “Other” as the framework, leave the build command empty, and use `.` as the output directory.
- Traditional hosting: upload every file and folder to `public_html` or the host’s web root.

Keep the `assets` folder beside `index.html`; the page uses relative paths.

## Editing

Search `index.html` for Ansa’s name, email, LinkedIn, GitHub, project descriptions, and store links. Colors, typography, spacing, and responsive breakpoints are defined in `styles.css`.

The résumé is located at `assets/ansa-zaheer-resume.pdf`.
